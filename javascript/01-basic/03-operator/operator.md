# 연산자

## 1. 산술 연산자

- +
- -
- *
- /
- %
- ** (지수)

- ++
- --

* 참고
- 피연산자 중 하나라도 문자열이면 '+'는 반대쪽 값도 문자열로 변환.
반대로 나머지 연산자는 전부 문자열을 숫자로 변환.

## 2. 비교 연산자

- >
- <
- >=
- <=
- ==
- === (값과 타입 모두)
- !=
- !== (값과 타입 모두)

## 3. 논리 연산자

- &&
- ||
- !

* 참고
- "" / 0 / NaN / null / undefined / false 모두 false 로 간주.

## 4. 대입 연산자

- =
- +=
- -=
- /=
- %=
- **=

## 5. 삼항 연산자

- ?:

조건식 ? 참일 때 실행할 값 : 거짓일 때 실행할 값

## 6. Null 병합 연산자

- ??

왼쪽 피연산자가 null 또는 undefined 일 때 오른쪽 피연산자를 반환하고, 그렇지 않으면 왼쪽 피연산자를 그대로 반환.

## 7. 옵셔널 체이닝 연산자

- ?.

프로퍼티가 없는 중첩 객체를 에러없이 안전하게 접근.
앞의 평가 대상이 null 이나 undefined 이면 평가를 멈추고 undefined 를 반환.
