# Frontend Study

웹 퍼블리셔 실무 경험을 기반으로 Frontend Developer로 전환하기 위한 학습 및 프로젝트 기록 저장소 입니다.

JavaScript를 기반으로 React, TypeScript를 학습하고, 실제 프로젝트를 통해 API 연동, 상태 관리, 테스트, 성능 및 접근성까지 단계적으로 익히는 것을 목표로 합니다.

---

## 🎯 Goal

> 기존 웹 퍼블리싱 경험을 React/TypeScript 기반의 Frontend 개발 역량으로 확장한다.

# 14. AI Coding Workflow

AI를 단순히 코드를 대신 작성하는 도구로 사용하지 않는다.

## 기본 workflow

문제 정의
    ↓
내가 해결 방법 생각
    ↓
AI에게 질문
    ↓
AI 코드 검토
    ↓
직접 실행
    ↓
동작 원리 이해
    ↓
필요한 부분 수정
    ↓
Git Commit

## 학습 원칙

* [ ] AI가 작성한 코드를 그대로 복사하지 않는다.
* [ ] 모르는 코드가 있으면 설명을 요청한다.
* [ ] 구현 전에 직접 설계해본다.
* [ ] 에러 메시지를 먼저 읽어본다.
* [ ] AI에게 디버깅 과정을 설명하게 한다.
* [ ] 최종 코드는 내가 설명할 수 있어야 한다.

# 공부 방법

각 주제는 다음 순서로 진행한다.

개념 이해
    ↓
간단한 예제 작성
    ↓
직접 변형
    ↓
작은 문제 해결
    ↓
실제 UI에 적용
    ↓
Markdown 정리
    ↓
Git Commit

## 한 주제를 끝냈다고 판단하는 기준

다음 질문에 답할 수 있으면 다음 단계로 넘어간다.

1. 이 기술은 무엇인가?
2. 왜 사용하는가?
3. 기본 문법은 어떻게 되는가?
4. 언제 사용하는가?
5. 비슷한 기술과 어떤 차이가 있는가?
6. 직접 간단한 코드를 작성할 수 있는가?
7. 실제 프로젝트에 적용할 수 있는가?

모든 내용을 완벽하게 외우는 것을 목표로 하지 않는다.

 **"필요할 때 찾아볼 수 있고, 왜 사용하는지 설명할 수 있으며, 직접 구현할 수 있는 수준"을 목표로 한다.**

## 🤖 AI Coding Workflow

AI Coding Agent를 단순한 코드 생성 도구가 아닌 개발 보조 및 검증 도구로 활용합니다.

Requirement
    ↓
Task Definition
    ↓
AI Agent
    ↓
Code Generation
    ↓
Code Review
    ↓
Test
    ↓
Refactoring
    ↓
Git Commit

AI가 생성한 코드를 그대로 사용하는 것이 아니라 코드의 동작 원리와 구조를 직접 검토하고 수정하는 것을 원칙으로 합니다.

---

## 🌱 Study Principles

### 1. 직접 작성한다

강의를 보는 것보다 직접 코드를 작성하는 것을 우선합니다.

### 2. 문제를 해결하면서 배운다

모든 개념을 미리 공부하기보다 프로젝트를 진행하면서 필요한 기술을 학습합니다.

### 3. 기록한다

학습 과정에서 발생한 문제와 해결 방법을 Git commit 및 문서로 기록합니다.

### 4. 기존 경험을 확장한다

기존 웹 퍼블리싱 경험을 기반으로 UI 구현 능력과 Frontend 개발 역량을 연결합니다.

### 5. 이해한 코드를 사용한다

AI가 생성한 코드라도 동작 원리와 구조를 이해한 후 프로젝트에 적용합니다.
